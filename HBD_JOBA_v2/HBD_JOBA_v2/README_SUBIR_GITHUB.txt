HBD_JOBA — versión con recuerdos y música

1) En tu repositorio HBD_JOBA, sube/reemplaza:
   index.html
   css/style.css
   js/script.js

2) Crea/sube estas carpetas y archivos:
   assets/fotos/ (14 JPG)
   assets/audio/entra-en-mi-vida-instrumental.mp3
   assets/audio/las-mananitas-pedro-fernandez.mp3

3) GitHub Pages debe apuntar a la rama principal (main) y a /root.

4) Después de subir todo, abre la página y usa Ctrl+F5.

La música no empieza al cargar la página. Empieza cuando se pulsa “Comenzar”, para evitar el bloqueo de autoplay del navegador.
